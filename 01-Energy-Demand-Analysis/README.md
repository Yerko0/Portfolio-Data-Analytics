# Análisis de Demanda Eléctrica con Python, PostgreSQL, SQL y Power BI

## Descripción

Este proyecto desarrolla un análisis de datos aplicado al estudio de la demanda eléctrica histórica
El objetivo es analizar patrones temporales y regionales de consumo eléctrico mediante un proceso reproducible que integra Python, Pandas, PostgreSQL, SQL y Power BI
El proyecto simula un escenario de análisis de datos en el que una empresa energética busca comprender el comportamiento histórico de la demanda para identificar patrones relevantes y generar información útil para la toma de decisiones

---

## Objetivos:

- Explorar y comprender datos históricos de demanda eléctrica
- Evaluar la calidad y continuidad temporal de los registros
- Limpiar y transformar los datos mediante Python y Pandas
- Almacenar los datos procesados en una base de datos PostgreSQL
- Realizar consultas analíticas mediante SQL
- Identificar patrones horarios, semanales, mensuales y regionales
- Analizar la evolución histórica de la demanda
- Construir un dashboard interactivo en Power BI
- Comunicar los principales hallazgos mediante visualizaciones y conclusiones
